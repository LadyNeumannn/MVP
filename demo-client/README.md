# Демо-клиент (НЕ часть тестового задания)

Простая HTML/JS страница для ручной проверки сценариев Client API.
В задании указано, что клиентскую часть реализовывать не нужно, так что
этот клиент существует только для собственного удобства при проверке
бизнес-сценариев.

Никакой сборки нет (нет npm/webpack/React)

## Запуск

1. Поднять бэкенд: `docker compose up` в корне репозитория.
2. Раздать эту папку любым статическим сервером, например:
   ```
   cd demo-client
   python3 -m http.server 5500
   ```
3. Открыть http://localhost:5500 в браузере.

Если `kuhnya` слушает не на `localhost:8080`, поменяйте `API_BASE`
в начале `app.js` (или задайте `window.API_BASE` до загрузки скрипта).
